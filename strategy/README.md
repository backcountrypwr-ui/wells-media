# Weekly strategy for the editor

Every Sunday the social media project reads the Instagram and YouTube numbers, the comments, and what's working for other creators in the niche, then writes this week's plan here.

- `latest.md`: this week's plan. Always read this one before cutting anything.
- `YYYY-MM-DD.md`: the same plan, kept for each week.

Each plan has the same sections:
1. **Editing rules this week**: hook, length, captions and pacing rules backed by the numbers.
2. **What's working**: our own top performers and why.
3. **Borrow from the niche**: competitor and trend formats worth copying, with the example to study.
4. **This week's videos**: one block per post with the day, platform, footage, first-second shot, on-screen text, length, structure, audio, caption and hashtags.
5. **Don'ts** and **data gaps**.

Nothing gets posted automatically. The owner approves every video, caption and account before it goes up. Finished cuts go in `reels/`.
